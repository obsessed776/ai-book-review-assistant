# AI Book Review Assistant
AI-асистент для пошуку та узагальнення відгуків про книги.

# Основні можливості
- Визначення назви та авторів з фотографії за допомогою LLM
- Пошук відгуків про книгу через Hardcover API
- Аналіз відгуків за допомогою LLM

# Запуск
Перед запуском необхідно налаштувати API-ключі.
```
cp .env.example .env
```
Для керування залежностями використовується uv.
Встановлення залежностей та запуск бота:
uv sync
uv run main.py
